# fig/ —— 插图目录

本目录存放讲义中引用的插图。正文里的 `\includegraphics` 只写**不带扩展名**的路径
（`png` / `jpg` / `pdf` 均可被自动识别），按下面的命名放图即可自动生效。

| 文件名 | 对应原文图 |
|:---|:---|
| `fig1-1.*` | Fig. 1.1 |
| `fig1-2.*` | Fig. 1.2 |
| … | … |
| `fig7-16.*` | Fig. 7.16 |

命名规则：`fig<章号>-<图号>.<任意图形扩展名>`。

每个图的位置在正文中都有 `\includegraphics[width=...]{fig/figX-Y}` 占位，
图注为中文；图注上方的一行 `%` 注释保留原文英文图注，供截图时对照。
